Enterprise Systems
Enterprise Platform
HYPE Innovation Management Platform
Deployed

The organization had no structured system to capture, evaluate, or track innovation initiatives. Ideas were lost in email chains and informal conversations with no accountability or lifecycle management.

Implemented HYPE as the enterprise innovation platform — configuring submission workflows, evaluation criteria, lifecycle stages, and stakeholder notification systems aligned to the organization's innovation process.

Enterprise-wide innovation pipeline with structured submission, multi-stage evaluation, and full lifecycle tracking — enabling leadership to see the innovation portfolio in real time.

Change management and training were as critical as technical configuration. Adoption required ongoing stakeholder engagement beyond the initial launch.

CRM System
Salesforce CRM Transformation
Deployed

Salesforce was implemented but underutilized — low adoption, poor data quality, and no standardized processes. Sales teams maintained their own spreadsheet pipelines outside the system.

Redesigned Salesforce configuration from the user backwards — simplifying fields, standardizing pipeline stages, automating data entry tasks, and building dashboards that made the CRM genuinely useful to reps.

Measurable increase in CRM adoption, improved data quality, and pipeline visibility that enabled more accurate forecasting at the leadership level.

CRM transformation is a UX problem as much as a technical one. The friction of data entry was the root cause of low adoption — not lack of features.

Internal Platforms
Internal Tool
Power Apps Project Management System
Deployed

Project status was tracked in scattered spreadsheets across teams. No centralized view, no ownership accountability, and no way for leadership to get a cross-team portfolio view.

Built a custom Power Apps application integrated with SharePoint as the data layer. Designed role-based views for contributors, managers, and executives — each seeing the information relevant to their context.

Single source of truth for project portfolio management — with real-time status tracking, ownership assignment, and automated progress reporting to leadership.

The most critical design decision was the executive view — simplifying complex project data into a single-screen portfolio summary that enabled faster decisions.

Developer Tool
Outlook Query Builder Add-in
Deployed

Teams were manually building complex email queries — copying templates, filling variables, formatting content — a process that was error-prone and consumed significant daily time.

Built a custom Outlook add-in using Office.js that provides a structured query-building interface directly in Outlook — generating correctly formatted email content from dynamic input fields.

Eliminated manual query formatting — reducing per-query time and removing a major source of formatting errors from outbound communications.

Tools embedded directly in existing workflows see dramatically higher adoption than standalone tools that require context switching.

Automation Systems
Workflow Automation
Want Brief Automation System
Deployed

Brief creation was entirely manual — no standard format, no automated handoff, and no visibility into brief status across the review and approval process.

Designed end-to-end automation using Power Automate: structured intake form → automatic brief generation from template → multi-stage approval routing → automated notifications and version control via SharePoint.

Standardized brief format, automated approval routing, and full audit trail — reducing brief cycle time significantly while improving brief quality and consistency.

Automation succeeds when the structured format provides real value to the user — not just to the process owner. Brief standardization reduced rework for the creative team, creating pull for adoption.

Reporting Automation
Automated Reporting Pipeline
Deployed

Weekly reports were manually compiled from multiple data sources — a process taking 3–4 hours per week with high risk of errors and inconsistent formatting.

Built automated data pipeline pulling from CRM, marketing platforms, and operational systems — aggregating into a standardized Power BI dashboard with automated weekly distribution to stakeholders.

Eliminated manual reporting effort — saving hours weekly and enabling real-time dashboard access instead of point-in-time weekly snapshots.

The hardest part was defining the "single version of the truth" — getting agreement on definitions before automating the numbers.
